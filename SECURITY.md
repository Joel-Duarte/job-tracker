# Security policy

Please do not include exploit details, credentials, or unreleased vulnerability information in a public issue or pull request. Use GitHub's **Security and quality → Report a vulnerability** option to send a private report. If that option is unavailable, open a public issue asking for a private contact channel without describing the flaw.

Maintainers can investigate CodeQL and Dependabot alerts in the repository Security tab. The **Jules security fix** GitHub Actions workflow can start a Jules task for an open alert on `master`; it does not automatically publish a branch or pull request. Review the proposed patch and tests before disclosure.
